# 轻印 · QuickPhotoPrint

一个离线的 Windows / macOS 单张照片打印小工具。支持常见相纸及自定义尺寸，内置 Brother-T735DW-Kodak-Glossy ICC，也可导入其他 RGB 输出 ICC / ICM。0.2.10 已在 0.2.9 内置 ICC 基础上，通过现有 `ColorAdjustment(red=-5)` 将红色 −5 直接写入 ICC 曲线；本次亮度、对比度、绿色、蓝色均新增 0。此前调整保留，界面额外微调仍默认为 0。

当前版本为 **0.2.11**，保留 0.2.10 已确认的内置 ICC。设置页只有内容超出可见区域时才显示滚动条，展开和收起设置不会改变表单宽度。

[下载轻印 Windows / macOS 版](https://github.com/Godles-lab/QuickPhotoPrint/releases/latest)

## 使用

1. 在空预览中央点“打开照片”，也可以直接拖入 JPG、PNG、TIFF、BMP、WebP；导入后从预览右上角选择其他图片。程序会按照片横竖调整相纸与预览（识别 EXIF 方向），正方形保留当前方向；仍可手动切换。照片只在本机读取，不上传，也不会写入程序目录。RAW / HEIC 请先导出为带色彩配置的 JPG。
2. 在“相纸”页先选择打印机，再选择相纸尺寸或输入毫米数；宽高与已有规格吻合时自动显示对应名称，例如 89 × 127 mm 显示“3R”，横向尺寸和恢复预设时同样识别。工具会匹配驱动原生纸张。当前打印机状态每 2 秒在后台查询，提交打印后立即查询一次，随系统队列更新在线、离线、正在打印、暂停或错误状态。点击“刷新打印机列表”重新读取全部队列，并保留仍可用的打印机、纸张类型、质量和份数。若需要无边框，可勾选“优先匹配无边框纸张”。
3. 选择“铺满区域”或“完整显示”。铺满以驱动允许的可打印区域和设置的留白为边界，普通纸张仍会显示驱动不可打印的白边。拖动照片调整位置，用滑块或百分比输入框调整缩放，旋转按钮每次顺时针 90°。“照片居中”将区域和照片一起移到整张相纸中心，更新成左右相等、上下相等的留白，保留缩放比例。
4. 输入“四边留白”并点“应用白边”可统一设置四边；下方的上、下、左、右可分别输入相对相纸边缘的留白，精确到 0.01 mm。数值不能小于驱动边距，剩余区域至少 5 × 5 mm。Shift + 拖动移动区域、拖绿色右下角方块调整大小时，四边数值同步更新。“恢复相纸区域”清除额外留白，恢复驱动允许的最大可打印区域及 100% 照片缩放。
5. 在 ICC 下拉列表中选择由打印机管理颜色、普通 RGB（sRGB）或 Brother·柯达·高光；其他 RGB ICC / ICM 从列表末尾导入。导入后可以点击该项右侧删除图标，或在展开列表中选中该项后按 Delete 移除。选择 ICC 后可设置渲染意图和黑点补偿。
6. 所有参数输入框、下拉菜单和滑块均禁用滚轮调值；滚轮只滚动设置页面。纸张类型选“系统打印窗口中选择”时，点“打印”会打开原生窗口核对参数；Mac 选择具体纸张类型时会先显示应用内确认，再直接提交 CUPS，Windows 始终使用系统窗口。应用内确认使用与相纸选择一致的名称和毫米尺寸，横向加注方向，无边框标记以实际匹配结果为准。纸张尺寸或可打印边距与预览不一致时，工具会停止提交，避免错误缩放。

照片载入与预览缩略图生成时，预览区域中央显示白色圆角进度卡。点击打印后，绿色按钮内显示流动进度条和当前处理阶段，直到提交完成；等待用户确认时暂停显示。进度条表示仍在处理，不显示估算百分比，也不代表打印机的实物出纸进度。处理期间暂时锁定照片和设置以防重复操作，成功、取消或失败后恢复；导入失败保留上一张照片。

“保存当前预设”会记住一套尺寸、构图和 ICC 参数，下次启动恢复；不记录或自动重开照片。导入配置列表及其文件路径自动保存在本机系统设置中，重复导入同一文件不会新增条目；文件本身不会复制或删除。移除当前或预设正在使用的导入配置时，对应颜色选择回到“由打印机管理颜色”。应用内选择的纸张类型、质量和份数会随预设保存；系统窗口内部的驱动设置仍请自行核对。

排版页的“预览尺寸补偿”默认收起，预览比例支持 **90%–200%**，默认 100%，可输入一位小数。它仅在预览中模拟打印机围绕相纸中心扩印后的大小与裁切；例如 106% 模拟放大 6% 后的可见范围。调整该值不会改变照片排版、打印尺寸或提交给打印机的图像，需要修改照片大小时使用“照片缩放”。

校准时固定打印机、相纸规格、介质、质量和无边框选项，用新版程序的一张实物打印作为参照，只调整“预览比例”直到画面大小和裁切位置吻合，再保存当前预设；调整预览期间无需反复重打同一排版。0.2.7 起，旧预设中的尺寸补偿值也仅用于预览。实际比例需要按同一套打印设置的实物结果确定。

界面预览始终显示原照片的色彩，只用于检查构图与排版。ICC 选择、微调滑块、渲染意图和黑点补偿均不改变预览颜色。

## ICC 颜色微调（0.2.5）

选择 RGB ICC 后，按需点击默认收起的“微调设置”，展开**亮度、对比度、红色、绿色、蓝色**五个滑块，也可直接输入 −50 至 +50 的数值。展开后仅保留说明“微调为打印后的颜色配置”。收起不会清除已有数值，重新启动时仍默认收起。参数作用于 ICC 转换后的打印照片；白边不参与调色。选择“由打印机管理颜色”时微调禁用并收起。

**0 表示在当前 ICC 基础上不再额外调整。** 之前 Brother 配置的 R112 / G131 / B125 是输入 128 时的曲线输出值，那套曲线以 128 为中性值。这里的五个滑块是另一层相对调整，不能用来读取或直接还原第三方 ICC 的原始生成参数；归零后，原 ICC 内已有的补偿和提亮仍然生效。

- “重置微调”将五个滑块归零，回到所选 ICC 的原有效果。
- 调整仅用于当前打印及另存的 ICC，实际打印效果需试印确认。拖动或点击滑块只更新数值，不转换或重新生成照片预览。
- “另存为 ICC…”使用系统原生保存窗口，系统按钮跟随系统语言，导出独立的新文件并保留源文件；保存成功后**不自动加入列表、不切换配置、不清空滑块**。用户需要时从 ICC 列表末尾自行导入。
- 切换或导入另一份 ICC 后，额外微调归零。新导出的文件已包含调整，所以导入后无需再次输入同一组数值。若想保留尚未导出的调整，可使用“保存当前预设”，恢复预设会同时恢复所选 ICC 和五个数值。

编辑器支持常见 ICC v2/v4 RGB 矩阵/曲线配置，以及 LUT8、LUT16、mAB/mBA 配置。各渲染意图的原始转换表分别保留，正向输出和反向输入曲线同步修改。特殊浮点 D2B/B2D 配置或不支持的结构会明确报错，不会写出只修改部分转换路径的文件。CMYK 不在本工具支持范围内。

Windows 与 Mac 使用相同的 ICC 文件和微调逻辑，默认额外微调均为 0；实际打印仍需按对应平台和驱动验证。格式实现参考 [ICC v4 规范](https://www.color.org/specification/ICC.1-2022-05.pdf)。

预览与打印共用照片排版和驱动边距，预览额外应用已校准的尺寸补偿。“优先匹配无边框纸张”是匹配偏好；实际边距以驱动报告为准，匹配失败时仍可能有白边。未能读取边距时界面会提示，不能将未知边距当作已验证的无边框能力。不同打印机切换后会重新读取边距并约束留白；驱动左右或上下边距不对称时，居中可能缩小区域以同时满足相纸居中和硬件限制。

## 系统打印窗口

工具会记住上次选择的打印机，并优先传入驱动提供的原生纸张标识（例如 Brother 的 3.5 × 5）。正常情况下无需再次选择尺寸。如果在系统窗口切换了打印机，或驱动恢复了自己的预设，仍需核对；最终尺寸不一致时不会提交打印。

Mac 的直接打印通过系统自带 `lp` 将 PDF 和经过白名单验证的单次任务选项交给 CUPS，不修改全局默认值。命令返回成功表示任务已被队列接收，不代表离线设备已经完成打印。纸张方向、无边框扩印和颜色仍需实物对照；Windows 没有复用这条路径。

Mac 原生窗口允许使用系统首选语言，Qt 标准对话框也加载匹配系统语言的翻译资源。第三方驱动自己的未翻译字段可能仍为英文。工具主界面目前为中文。

## 颜色与无边距

- 内嵌源 ICC 会先转换为 sRGB；无源 ICC 的 RGB 照片按 sRGB 处理。
- 选择输出 ICC 时，Little CMS 实际执行颜色转换，再提交 RGB 光栅给系统打印引擎。仅支持 RGB 输出 ICC，CMYK 输出配置会拒绝加载。
- 使用 ICC 时，请关闭驱动额外的色彩增强，避免与之前的 Windows 红绿蓝调整叠加。
- 不同系统/驱动可能继续进行颜色处理，尤其 macOS ColorSync / AirPrint。**目前尚未验证实物打印与 Photoshop 完全一致，先用一张相纸对比。** 不能把软件数值测试通过当成实物色准保证。
- “铺满区域”表示排版裁切。真正打印到纸边，需要打印机/驱动支持该相纸尺寸的无边距模式；本工具不能绕过硬件不可打印边距。
- 自动测试涵盖几何、ICC、EXIF、界面控制及 PDF 输出；实物打印效果仍需使用对应打印机和相纸验证。

## 下载与运行

从 [GitHub Releases](https://github.com/Godles-lab/QuickPhotoPrint/releases/latest) 下载对应平台 ZIP。Windows 解压整个目录后运行 `QuickPhotoPrint.exe`，保留同目录的 `_internal` 文件夹。Mac 解压后将 `QuickPhotoPrint.app` 放入“应用程序”。当前版本没有商业代码签名或 Apple 公证；macOS 如阻止打开，可在“系统设置 → 隐私与安全性”中核对来源后允许打开，无需关闭系统安全保护。

支持目标：Windows 10/11 x64、macOS 13+ Apple Silicon / Intel。应用包无需安装 Python；各平台构建和验证结果以对应 Release 说明为准。

## 开发

需要 Python 3.12。在此目录运行：

```sh
python -m pip install -r requirements.txt
python app.py
```

测试与构建：

```sh
python -m pip install pytest==9.0.2 pypdf==6.7.1 pyinstaller==6.19.0
python -m pytest -q
python build.py
```

Windows exe 必须在 Windows 构建，macOS app 必须在 macOS 构建。无需提交个人照片作为样本；测试使用程序生成的纯色图。

源代码使用 MIT 许可；第三方库及 ICC 说明见 `THIRD_PARTY.md` 和仓库根目录 README。
