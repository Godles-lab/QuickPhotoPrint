# 内置 ICC

轻印内置 `Brother-T735DW-Kodak-Glossy.icc`，在应用中显示为“Brother·柯达·高光”。这是针对 Brother DCP-T735DW 与柯达高光照片纸，通过个人试印调整得到的经验配置；其他设备、纸张、墨水或驱动需单独试印确认。

## 使用

在轻印的“颜色”页选择该配置即可。当前文件已经包含最终确认的颜色调整，界面额外微调默认全部为 0。配置文件也可以单独下载，用于支持 RGB 输出 ICC 的其他打印软件。

- 将 ICC 作为打印输出配置，不要用它替换照片原有的源色彩配置。
- 使用 ICC 管理颜色时，核对驱动是否还启用了额外的色彩增强或纠偏。
- 内置配置是个人经验补偿，不是 Brother / Kodak 官方配置，也不是通过测色仪建立的打印机校准文件。
